What you are scoring:

  • You will be given a General Prompt and three Base Prompts (Base Prompt A, Base Prompt B, and Base Prompt C). The General Prompt is meant to be a more abstract / generalized version that covers the Base Prompts.
  • For each prompt, you will give two separate scores from 0 to 1: a Faithfulness score and an Informativeness score. These measure different things — please read both definitions carefully.
  • After the two scores for each prompt, write a brief reason (one or two sentences) covering both.

1. Faithfulness — Does the General Prompt stay true to the Base Prompt, or does it add things the Base Prompt does not ask for?

  • Score = the fraction of the distinct details in the General Prompt that are present in, or implied by, the Base Prompt. (This is the same judgment the old single score asked for.)
  • The only thing that lowers this score is a detail the General Prompt states that the Base Prompt does not support — an invented task, domain, or constraint.
  • It is completely fine (never penalized) for the General Prompt to be broad, abstract, or to leave out details from the Base Prompt. A General Prompt that drops detail but invents nothing is fully faithful (1.00).
  • Implied support counts fully — a detail need not appear word-for-word in the Base Prompt; if the Base Prompt clearly implies it, it is grounded.

2. Informativeness — How much of the important content of the Base Prompt does the General Prompt actually capture?

  • Score = the fraction of the Base Prompt's important content (its core intent, domain, main task, key constraints) that is present in, or implied by, the General Prompt.
  • Penalize vagueness: a General Prompt so abstract that it barely tells you what the Base Prompt is about (e.g. "writing code", "analyzing data") is uninformative, even if it is technically true.
  • Do not reward the General Prompt for content that is not in the Base Prompt.
  • Look for semantic coverage, not word-for-word detail: if the General Prompt correctly identifies the task type and domain, it can still score high even if it drops a specific tool or minor constraint.

Key point — the two scores can disagree:

  • Abstraction / leaving things out lowers Informativeness only, never Faithfulness.
  • Inventing / adding / contradicting lowers Faithfulness only.
  • Example: for a detailed Base Prompt, a General Prompt like "Write a program that uses AI to play a game" can be fully faithful (it invents nothing) yet very uninformative (it drops almost everything specific). See Example 3 below.

How to read the FAITHFULNESS buttons:

  • 1.00 — Fully faithful: everything the General Prompt says is present in or implied by the Base Prompt; it invents nothing (being broad or dropping detail is fine).
  • 0.75 — Mostly faithful: nearly all supported; one detail the Base Prompt only weakly or partially implies.
  • 0.50 — Partially faithful: a mix of supported content and a clear detail/constraint the Base Prompt does not support.
  • 0.25 — Mostly unfaithful: the General Prompt adds a task or constraint the Base Prompt does not support.
  • 0.00 — Not faithful: the General Prompt describes something absent from or contradicting the Base Prompt.

How to read the INFORMATIVENESS buttons:

  • 1.00 — Excellent coverage: captures essentially all of the Base Prompt's important content; drops only minor specifics.
  • 0.75 — Good coverage: captures the core domain and main task but loses several important specifics.
  • 0.50 — Vague: captures the broad activity type but little of the Base Prompt's structure or topic.
  • 0.25 — Mostly uninformative: captures almost none of the important content; far too generic.
  • 0.00 — Uninformative / mismatched: captures none of the important content, or miscategorizes the task.

Examples (each shows both scores; note how Faithfulness can stay high while Informativeness drops):

  • Example 1 (good summary — high on both):

      Base Prompt: Write a Python script that uses the Hugging Face Transformers library to fine-tune a BERT model for sentiment analysis on a custom dataset. Include data preprocessing using the datasets library, tokenizer usage, training loop with Trainer, and evaluation metrics such as accuracy and F1-score. Also, provide inline comments to explain each step.

      General Prompt: Create a Python program that demonstrates how to fine-tune a pre-trained NLP model using the Hugging Face Transformers library on a labeled dataset for a text classification task. The program should show preprocessing, tokenization, training, and evaluation, and include explanations in the code.

      Faithfulness: 1.00 — every detail the General Prompt states (Python, Hugging Face, fine-tuning, text classification, preprocessing, tokenization, training, evaluation, explanations) is present in the Base Prompt; it invents nothing. Informativeness: 0.75 — it captures the core task and domain but drops a few specifics (the exact model BERT, the F1 metric).

  • Example 2 (faithful, but loses specifics):

      Base Prompt: Implement a convolutional neural network (CNN) from scratch using PyTorch to classify handwritten digits from the MNIST dataset. The implementation should include custom-defined layers, training and validation loops without using torchvision.models, and visualizations of training loss and accuracy curves using Matplotlib.

      General Prompt: Create a PyTorch-based image classification model for a standard dataset, avoiding pre-built architectures and training it from scratch.

      Faithfulness: 1.00 — everything it states (PyTorch, image classification, standard dataset, from scratch, no pre-built architectures) is supported by the Base Prompt; being broad costs nothing. Informativeness: 0.50 — it loses several important specifics: the MNIST dataset, the custom-layer requirement, and the loss/accuracy visualizations.

  • Example 3 (fully faithful, but uninformative):

      Base Prompt: Develop a deep reinforcement learning agent using Python and TensorFlow 2. Implement the Deep Q-Network (DQN) algorithm to solve the CartPole-v1 environment from OpenAI Gym. The agent should include experience replay, target network updates, and an ε-greedy exploration strategy. Provide a training loop and visualize rewards over episodes.

      General Prompt: Write a program that uses AI to play a game.

      Faithfulness: 1.00 — its few details ("a program", "uses AI", "play a game") are all implied by the Base Prompt, so it invents nothing. Informativeness: 0.25 — it captures almost none of the important content (reinforcement learning, DQN, TensorFlow, CartPole); it is far too generic.

  • Example 4 (unfaithful — the General Prompt invents something):

      Base Prompt: Write a Python script that uses Hugging Face Transformers to fine-tune a BERT model for sentiment analysis, with preprocessing, tokenization, a Trainer loop, and accuracy/F1 evaluation.

      General Prompt: Write a program that processes and manages structured data, implementing user-facing operations with organized output.

      Faithfulness: 0.25 — "implementing user-facing operations" is invented; the Base Prompt trains a model and has no user-facing component. Informativeness: 0.25 — it miscategorizes the task and misses the important content (machine learning, fine-tuning BERT, sentiment analysis, the NLP domain).

  • Score Base Prompt A and Base Prompt B independently, and score Faithfulness and Informativeness independently of each other.
  • If you have any additional comments or suggestions for the requester, please use the field for additional comments at the bottom.
  • If you have seen this set of prompts in a previous run, please skip the task until you see prompts you haven't seen.
  • Your responses will be examined manually by the requester and/or judged by other workers. The reviewing might take some time, so you might need to wait for several days to get the payment. We will provide more working opportunities to workers who score carefully and write clear reasons.
